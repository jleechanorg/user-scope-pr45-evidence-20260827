# Methodology

This is Layer 2 real-callstack evidence captured on the target Linux machine against live user services and the real installed Codex CLI. `capture_evidence.sh` recorded the repository and remote SHA, pre/post porcelain status, tracked-file index digest, diff-index/worktree/cache checks, selected credential-free source changes, systemd/cgroup state, loopback listeners, a direct listener-PID → `/proc/PID/cgroup` → `mcp-daemon.service` check, systemd process tree, direct curl MCP initialize calls with retained response headers/bodies, client configuration, a fresh Codex turn inside tmux, focused tests, shell lint, and redacted secret scans. `request_responses.jsonl` is explicitly an assembled index of each submitted JSON payload and its retained response, not an independently captured wire trace.

The terminal session was captured as asciicast, rendered to GIF, encoded to MP4 with burned-in captions, and sampled at one frame per second with `ffmpeg`. Sample frames were visually inspected. Paths, session identifiers, and potential credential values are sanitized or withheld. The explicit Google OAuth marker scan checks for common `GOCSPX-`, `ya29.`, `1//`, and `AIza...` forms without printing matching values.

The complete checksum-bound sanitized bundle is published as a public archive, including the capture script and all 51 extracted frames; its GIF is embedded and its MP4 is directly downloadable from PR #45. A linked unlisted gist provides the exact branch/SHA checkout, dependencies, commands, expected results, and public media links. Publication improves independent reproducibility but does not change the recorded single-host scope.
